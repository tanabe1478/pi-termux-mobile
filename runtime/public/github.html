確認しています…

スマホ内のgitで、非公開リポジトリのcloneやpushに使います。SSH認証とは別です。

トークンの作成

  1. GitHubでfine-grained PATを作成
  2. 有効期限と、開発したいリポジトリだけを指定
  3. Repository permissionsのContents: Read and writeを許可（cloneのみならRead-only）
  4. 発行したトークンを上の専用欄へ入力

組織によっては承認が必要です。認証成功は、すべてのリポジトリや操作へのアクセスを保証しません。ワークフローの編集などには追加の権限が必要です。

トークンはアプリの私有領域に保存します。チャット・URL・リポジトリには貼り付けないでください。「削除」は端末内の保存を削除するだけです。失効はGitHubの設定から行ってください。
